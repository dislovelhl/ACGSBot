## Install an agent CLI

ACGS needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart ACGS.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Using ACGS at work

If your company uses OpenMaus Admin, you can sign in with your organization to use the AI models it provides, alongside your own. It is optional. See [Use ACGS at work](./organisation.mdx).

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/dislovelhl/ACGSBot.git
cd ACGSBot
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

ACGS stores its application data under `~/.openmausbot`. Electron window and browser data use the normal per-platform application data directory.
